# 05-Naming-Convention.md

# The Treadmill Method
## Naming Convention Guide v1.0

---

# Objetivo

Este documento define o padrão oficial de nomes para todos os arquivos do projeto The Treadmill Method.

Todos os arquivos futuros devem seguir obrigatoriamente esta convenção.

Nunca criar nomes arbitrários.

Nunca utilizar espaços.

Nunca utilizar letras maiúsculas.

Nunca utilizar caracteres especiais.

---

# Idioma

Todos os nomes devem ser escritos em inglês.

Nunca utilizar português.

---

# Letras

Sempre:

lowercase

Exemplo

✔ sarah-after.png

Nunca

❌ Sarah-After.png

❌ Sarah After.png

---

# Separadores

Sempre utilizar hífen.

✔ walking-natural.png

Nunca

walking_natural.png

walking natural.png

walkingNatural.png

---

# Extensão

Todos os arquivos de imagem:

.png

Todos os vídeos:

.mp4

---

# Estrutura Oficial

personagem-categoria-variação-versão.extensão

Exemplo

sarah-walking-natural-v1.png

---

# Objetivo

Ao ler um nome de arquivo, qualquer pessoa deve saber imediatamente:

- quem é o personagem;
- qual categoria;
- qual variação;
- qual versão;
- qual status.

Exemplo

denise-walking-natural-v2-final.png

Sem abrir o arquivo é possível saber:

✔ personagem

✔ categoria

✔ pose

✔ versão

✔ status

---

# Checklist

Antes de salvar um novo ativo verificar:

□ Nome em inglês

□ Minúsculas

□ Hífens

□ Sem espaços

□ Sem caracteres especiais

□ Categoria correta

□ Personagem correto

□ Versão correta

□ Extensão correta (.png ou .mp4)

---

# Princípio Final

A biblioteca de ativos deve continuar organizada quando atingir:

100 arquivos

500 arquivos

1.000 arquivos

Se a convenção não suportar esse crescimento, ela deve ser considerada incorreta.
